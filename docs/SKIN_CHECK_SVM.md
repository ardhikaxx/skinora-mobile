# Penerapan Model SVM pada Fitur Skin Check

Model kecerdasan buatan Support Vector Machine (SVM) pada fitur Skin Check dilatih langsung dari dataset `assets/dataset/skin-type.csv` yang berisi 2.000 baris data seimbang untuk empat kelas tipe kulit, yaitu Dry (Kering), Normal, Oily (Berminyak), dan Combination (Kombinasi), dengan tujuh fitur berupa Age, Gender, Hydration_Level, Oil_Level, Sensitivity, Humidity, dan Temperature. Dataset tersebut didaftarkan pada berkas `pubspec.yaml` di bagian aset Flutter agar ikut terpaket ke dalam aplikasi saat dijalankan maupun diuji.

Algoritma inti SVM ditulis murni menggunakan bahasa Dart pada berkas `lib/services/skin_svm_classifier.dart` melalui kelas `MinMaxFeatureScaler` untuk normalisasi fitur ke rentang nol hingga satu, `BinaryRbfSvm` yang menerapkan optimasi Sequential Minimal Optimization (SMO) dengan kernel Radial Basis Function (RBF), serta `MultiClassRbfSvm` untuk klasifikasi multi-kelas strategi One-vs-Rest beserta estimasi probabilitas keyakinan. Pemilihan kernel RBF dilakukan karena distribusi data pada dataset bersifat non-linear, di mana kelas Dry, Normal, dan Oily berada pada rentang kelembapan dan suhu tertentu yang dikelilingi oleh kelas Combination.

Penghubung antara dataset, model SVM, dan antarmuka kuesioner berada pada berkas `lib/services/skin_svm_service.dart` melalui kelas `SkinSvmService` yang membaca CSV, melatih dan menyimpan model di cache memori lewat `ensureModel`, mengonversi jawaban kuesioner berbahasa Indonesia menjadi vektor numerik tujuh dimensi lewat `predict`, serta menghasilkan tipe kulit, tingkat sensitivitas, risiko jerawat, dan tingkat keyakinan model. Pada sisi antarmuka pengguna, halaman `lib/pages/pengguna/skin_check_page.dart` memanggil `SkinSvmService.ensureModel` saat halaman dibuka untuk menyiapkan model lebih awal, lalu halaman `lib/pages/pengguna/skin_check_question5_page.dart` memanggil `SkinSvmService.predict` saat pengguna menekan tombol Lihat Hasil sebelum menyimpannya melalui `lib/services/skin_service.dart` ke subkoleksi `users/{uid}/skin_checks`. Hasil klasifikasi beserta badge keyakinan model RBF-SVM dan tips perawatan yang disesuaikan ditampilkan pada `lib/pages/pengguna/skin_check_result_page.dart`, sedangkan daftar riwayat dan pembukaan ulang detail hasilnya ditangani oleh `lib/pages/pengguna/riwayat_skin_check_page.dart`, dengan cakupan pengujian otomatis pada berkas `test/skin_svm_test.dart`.
